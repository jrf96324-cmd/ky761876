# 室內空間 3D 設計器

## 單機版（不需網路、不需安裝）
直接用 Chrome／Edge 開啟 **`dist/interior-designer-offline.html`**（單一檔案，已內嵌 Three.js r128，可複製到隨身碟或內網電腦使用）。
專案資料自動存在該瀏覽器，也可用「專案存取」匯出／匯入 JSON。

原始碼：`index.html` + `app.js` + `export.js` + `vendor/three.min.js`；修改後執行 `python3 build.py` 重新產生單機版。

## 匯出
- **匯出 3D STEP**：ISO 10303-21 AP214（AUTOMOTIVE_DESIGN），單位 mm，原點在房間內側西南角（X 東、Y 北、Z 上）。
  組立結構：根組立＝專案名稱；`ROOM_…` 零件含牆、地坪、門窗；每件家具一個零件（`01_品名`），每個零件由多個平面 B-rep 實體組成並帶顏色。
  圓柱與球體以多面體近似（圓柱 24 邊、球 60 面）。可匯入 Creo、SolidWorks、Inventor、Fusion 360、FreeCAD。
- **匯出 2D PDF**：A3 橫式，含圖框與標題欄（專案名稱、圖名、比例、日期、頁次）。
  第 1 頁平面配置圖依標準比例（1:20～1:300 自動選擇）並標註牆面門窗分段尺寸與家具尺寸；第 2 頁等角／前／右／俯視圖；
  之後為家具清單、估價單、裝修材料計算、動線檢查、系統櫃拆單。每頁為 150 dpi 影像（中文字不需字型嵌入）。
- Chrome／Edge 會跳出「另存新檔」視窗；其他瀏覽器直接下載。

## 功能
- **空間參數**：房間 W/D/H、牆厚、用途、地板材質、天花板、牆色、吸附格點、最小通道寬。
- **家具庫**（8 類、30+ 件）：沙發、床（台規 3.5/5/6 尺）、衣櫃、餐桌椅、書桌、廚具、冰箱、衛浴、系統櫃、盆栽燈具。
- **3D 擺設預覽**：拖曳家具移動、自動剖切靠近視角的牆、等角/前/右/俯視、尺寸標籤。
- **平面配置圖**：拖曳家具與門窗、選取後顯示離四面牆尺寸、門片開啟扇形、前方操作空間。
- **門窗開口**：門、拉門、窗（含窗台高）、開口，可設定牆面、位置與尺寸。
- **動線檢查**：家具重疊、通道寬不足、擋門、櫃體/廚具/冰箱前方操作空間、遮擋窗戶。
- **裝修材料計算**：地板叫料（含損耗、磁磚片數）、油漆面積與用量、天花、踢腳板、照明流明法、空調 kW 估算。
- **系統櫃拆單**：側板、頂底板、層板、背板、門板/抽屜尺寸，板材張數、封邊長度、鉸鏈/把手/滑軌。
- **估價單**：家具＋工程＋設計費＋管理費＋營業稅，所有單價可修改。
- 匯出 CSV、匯出圖片、專案 JSON 存取、復原、自動保存於瀏覽器。

快捷鍵：`R` 旋轉 90°、方向鍵微調（Shift 為 10 mm）、`Delete` 刪除、`Ctrl+D` 複製、`Ctrl+Z` 復原。
