② 運轉條件

內部繼電器固定：M0 運轉中、M1 單循環結束、M50 異常。延時計時器 T1～，逾時計時器 T101～（K 值以 0.1 秒為單位）。

③ 動作步序（時序）

輸出欄：Y1 僅此步 ON、+Y2 進入此步時 SET 保持、-Y2 RST。完成條件：& 串聯、| 並聯、! B 接點，如 X13 & !X14 | X5。

在 GX Works2 / GX Developer 清單模式自動逐行輸入指令，等同人工鍵入，所有軟體版本都能用。

專案資料 JSON

I/O 表 + 步序表，可存檔後再載入繼續編輯。

匯入檔案格式（程式 CSV / 裝置註解 CSV）

導入 PLC 的建議流程
  1. 先校準一次：在您的 GX Works2 / GX Developer 隨便寫兩行（LD X0、OUT Y0），用軟體的「匯出 CSV / 寫入 CSV 檔案」存檔，再用上方「校準」讀入。之後本工具產生的 CSV 會完全照該版本的欄位、編碼、分隔符號輸出。裝置註解也照此做一次。
  2. 方法 A：CSV 匯入：GX Works2 / GX Developer 以「從 CSV 檔讀取」（GX Developer 為「專案 → 匯入檔案 → 從 TEXT/CSV 格式檔案匯入」）讀入程式 CSV 與註解 CSV。
  3. 方法 B：自動鍵入（最通用）：安裝 AutoHotkey v2，執行下載的 .ahk → GX Works2 開新程式 → Alt+F1 切清單模式，游標放在第 0 步 → 腳本提示後 5 秒內點選 GX Works2 視窗，程式會逐行自動輸入；按住 Esc 可中止。
  4. GX Works3（FX5U / iQ-R）：無清單模式。先在 GX Works2（機種選 FX3U 或 Q）以 A/B 方法建好，再用 GX Works3「專案 → 開啟其他格式檔案 → GX Works2 格式」轉換並變更機種；註解 CSV 可直接讀入。
  5. 導入後執行「轉換（F4）」與「程式檢查」，確認無雙線圈、裝置範圍正確，再「寫入 PLC」。

選單名稱依軟體版本與語系略有不同。安全迴路（緊急停止、光柵）必須以硬體配線實現，PLC 程式只作狀態監控。
