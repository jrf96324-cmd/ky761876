# 三菱 PLC 階梯圖產生器

## 單機版

直接用瀏覽器（Chrome / Edge）開啟 **`三菱PLC階梯圖產生器_單機版.html`**，不需安裝、不需網路。
資料自動保存在瀏覽器本機；可用「專案資料 JSON」存檔 / 載入。

修改 `index.html` 後執行 `node build-offline.mjs` 重新產生單機版。

## 功能

1. **I/O 配置表 + 動作步序（時序）→ 自動產生指令表 (IL)**
   - 步序法：M100（STEP0 待機）→ M101… 以 SET/RST 移步
   - 運轉自保持（M0）、停止、緊急停止（B 接點）、復歸、單循環 / 連續循環
   - 每步延時計時器 T1～、逾時計時器 T101～ → 異常 M50 → 異常燈閃爍
   - 輸出寫法：`Y1`（該步 ON）、`+Y2`（SET 保持）、`-Y2`（RST）
   - 完成條件：`&` 串聯、`|` 並聯、`!` B 接點
2. **指令表 → 階梯圖 (SVG)**：支援 LD/LDI/LDP/LDF、AND/ANI/ANDP/ANDF、OR/ORI/ORP/ORF、
   ANB/ORB、MPS/MRD/MPP、比較接點（LD= 等）、INV/MEP/MEF、OUT/SET/RST/PLS/PLF 與應用指令
3. **檢查**：雙線圈、FX 系列 X/Y 8 進位位址、未定義 I/O、ANB/ORB/MPS 配對
4. **匯出**：IL 文字檔、程式 CSV、裝置註解 CSV、階梯圖 SVG、專案 JSON
5. **導入 PLC 軟體**
   - CSV 編碼可選 Big5 / Shift-JIS / UTF-16 / UTF-8，分隔符號逗號 / Tab，FX 裝置 X000 補零
   - **格式校準**：讀入一份由您的 GX Works2 / GX Developer 匯出的 CSV，自動偵測編碼、分隔符號、前置行與欄位位置，之後照同一格式輸出
   - **AutoHotkey v2 自動鍵入腳本**：在 GX Works2 / GX Developer 清單模式（Alt+F1）逐行自動輸入，Esc 中止、失去焦點自動暫停
   - GX Works3（FX5U / iQ-R）：先在 GX Works2 建立，再以「開啟其他格式檔案」轉換

## 流程圖 → 階梯圖（SFC 式）

- 一個專案可有多個**並行流程**（例如左站、右站），各自的步序繼電器（M100～、M200～）。
- 每步：動作說明、輸出（`Y1` / `+Y2` SET / `-Y2` RST）、完成條件、**下一步**（空白＝下一列，`0`＝回待機）、**分支條件／分支至**（NG、重試）、延時、逾時。
- 共用設備（如 Robot）以對方流程的步序繼電器互鎖，例：`X13 & !M204 & !M207`。
- 「流程圖」分頁自動畫出 SFC 式流程圖（可匯出 SVG），模擬時目前步序會亮起。
- 可從 Excel「作業流程」表直接複製貼上，依 Step 編號建立步序。
- 內建範例：**普利珠與 PLATE 自動化組裝機**（左站 PLATE 壓入 + 右站普利珠裝填，共用 Robot、視覺定位、NG 分支）。

## 時序圖與接線圖

- **時序圖**：以「自動通過」模擬跑完一個循環，記錄各流程步序、全部輸出 Y、輸入 X 的 ON/OFF 時間，可匯出 SVG。
- **接線圖**（依 I/O 表與註解自動產生，可匯出 SVG）：
  - E-01 主電源與控制電源：QF1、PLC 電源、PS1 24VDC（依負載估算容量）、F1、P24／0V、K10 安全 24V（P24S）、QF2→KM1 動力負載。
  - E-02 安全迴路：急停雙迴路、安全門雙迴路、安全復歸 → 安全繼電器 K10 → KM1、P24S、PLC 監視。
  - E-03～ PLC 輸入／輸出接線：元件符號與代號（SB、SQ、B、SP、YV、KA、HL、HA、外部控制器）、線號、端子 TB1／TB2、PLC 點位與 COM 群組；危險輸出由 P24S 供電。
  - 輸入 Sink／Source、輸出電晶體 Sink／Source／繼電器可切換；自動建議 PLC 型號（含 20% 預留）。
- **端子台／線號表 CSV**：端子、線號、PLC 點位、元件代號、說明、建議線色線徑。
- 圖面為設計初稿，須經電控工程師依實際元件規格審核。

## 安全保護、防呆與導引標示

- **安全保護**：緊急停止（B 接點，A01）、防護門互鎖（A02）、安全光柵（A03）、氣壓檢知 1 秒確認（A04）；安全條件 M60 串接在運轉自保持與「危險輸出」迴路，條件不成立時危險輸出強制 OFF、保持型危險輸出復歸。
- **防呆**：啟動按鈕上升沿（LDP）、雙手啟動 0.5 秒同時、原點確認啟動許可（M62）、停止按鈕 B 接點選項、互斥感測器矛盾檢查（A10～）、每步逾時個別異常（A20～，含原因與處置）、流程互鎖、NG 分支、雙線圈檢查。
- **異常**：重異常 M50 停機並保持到復歸（異常燈閃爍、蜂鳴器，停止鈕可消音）；輕異常 M51 只警告（異常燈常亮）；可自訂異常條件、訊息與處置導引（A80～）。
- **導引標示**：D100 異常代碼、D101 操作導引代碼（待機／未在原點／警告／氣壓不足／防護門開啟／光柵遮斷／異常停止／急停中／運轉中），可直接給人機 GOT；程式迴路以【安全】【防呆】【異常】【導引】【步序】【輸出】標註；模擬畫面頂端即時顯示導引與異常處置；可匯出「異常與導引訊息表 CSV」。

## 進階功能

- **雙向編輯**：GX Works2 / GX Developer 修改後匯出的程式 CSV（或指令表 TXT）、裝置註解 CSV 可讀回本工具，看階梯圖、模擬、再匯出；讀回的 CSV 同時作為匯出格式範本。
- **模擬運轉**：直接執行指令表（LD/AND/OR/ANB/ORB/MPS/MRD/MPP、邊緣接點、比較接點、OUT/SET/RST/PLS/PLF、T/C、ZRST/MOV/INC/DEC/ADD/SUB/MUL/DIV、M8002/SM402、M8013/SM412 等），
  輸入 X 可點擊或按住，階梯圖即時亮起導通的接點與線圈，顯示目前步序、計時器現在值，可 ×1/×5/×10 加速。
- **慢動作 / 換步暫停 / 講述**：速度 ×0.1～×10；勾選「換步時暫停」可逐步講解；「目前階段與步序」顯示每個流程的階段層序、目前步、動作輸出、等待條件（✓/✗ 即時判斷）、延時與逾時計時，並記錄講述紀錄，可開啟語音講述。
- **模擬模式**：
  - 自動通過（從頭至尾）：自動啟動，每步停留設定秒數後自動讓等待中的 X 條件成立（只在步序互鎖、計時器已允許時），全部流程跑完一個循環後暫停；可勾選連續循環。
  - 手動（逐階段）：點階段按鈕或流程圖上的步序框，跳到該步並自動通過該階段後暫停；另有單步、跑完整流程、回待機；其他流程可維持待機。
  - 手動輸入：自行點選 X 輸入。
  - 流程圖：目前步序藍色、本循環已完成步序綠色；動作示意：動作中／復歸中橘色、到位藍色；被自動通過強制的 X 以橘框標示並寫入講述紀錄。
- **動作示意**：依輸出註解自動顯示缸、轉盤、震動盤、Robot（含 Job 編號）、視覺、夾爪、指示燈的簡易動畫圖示與感測器燈號。
- **虛擬機構**：設定「輸出 Y → 動作端 X / 原位端 X / 動作時間」，模擬氣缸感測器自動回授，整個循環可自動跑完。
- **共用專案（線上版）**：在 claude.ai 線上版可把專案存到共用區，被分享的同事開啟同一頁即可載入、修改、再儲存；對方更新時會提示「載入最新」，覆蓋前需再確認。單機版以專案 JSON 檔交換。

| iQ-R | GX Works3 | SM402 | SM412 | 16 |

## 注意

- 程式 CSV 的步號為 FX 系列估算值；CSV 匯入格式隨 GX Works / GX Developer 版本不同，首次使用請先以小程式確認。
- 匯入後請在 GX Works 執行轉換（F4）與程式檢查再寫入 PLC。
- 緊急停止等安全迴路必須以硬體配線實現，PLC 程式只作監控。
