FX 系列 X/Y 為 8 進位（X7 之後是 X10）；Q / iQ-R 為 16 進位。註解會帶入階梯圖與裝置註解 CSV。

裝置註解

② 運轉條件

內部繼電器固定：M0 運轉中、M1 單循環結束、M50 異常。延時計時器 T1～，逾時計時器 T101～（K 值以 0.1 秒為單位）。

③ 動作步序（時序）

輸出欄：Y1 僅此步 ON、+Y2 進入此步時 SET 保持、-Y2 RST。完成條件：& 串聯、| 並聯、! B 接點，如 X13 & !X14 | X5。

可直接貼上或修改三菱指令表（LD/LDI/LDP/AND/ANI/OR/ORI/ANB/ORB/MPS/MRD/MPP/OUT/SET/RST/PLS/PLF/比較接點/應用指令…），修改後按「重繪階梯圖」。; 之後為註解。

指令表 IL（.txt）

Tab 分隔「指令 裝置」，適合 GX Works2 清單模式輸入或對照鍵入。

程式 CSV（GX Developer 清單格式）

步號 / 指令 / 裝置 / 註記欄位。步號為 FX 系列估算，匯入後以軟體重新轉換為準。

裝置註解 CSV

「裝置, 註解」兩欄，含 I/O 與自動產生的 M / T 註解。

階梯圖 SVG

向量圖，可插入規劃評估報告、Word / PPT 或列印。

專案資料 JSON

I/O 表 + 步序表，可存檔後再載入繼續編輯。

匯入 GX Works 的建議流程
  1. 裝置註解：GX Works2 / GX Works3 開啟「裝置註解」編輯畫面 → 從 CSV 讀取（選單名稱依版本略有不同），選本頁的裝置註解 CSV。
  2. 程式（GX Works2，FX3U / Q）：階梯圖畫面按 Alt+F1 切成清單（List）顯示，依指令表輸入；或用 GX Developer「專案 → 匯入檔案 → 從 TEXT / CSV 格式檔案」讀入程式 CSV，再以 GX Works2 開啟該專案。
  3. 程式（GX Works3，FX5U / iQ-R）：在階梯圖編輯器直接鍵入每行指令（例 LD X0 Enter），階梯會自動成形；或先在 GX Works2 建好再用 GX Works3「開啟其他格式專案」轉換。
  4. 匯入後執行「轉換（F4）」與「程式檢查」，確認無雙線圈、步號與裝置範圍正確，再寫入 PLC。

CSV 匯入格式會隨 GX Works / GX Developer 版本變動，首次使用請先用一段小程式確認可讀入。安全迴路（緊急停止、光柵）必須以硬體配線實現，PLC 程式只作狀態監控。
