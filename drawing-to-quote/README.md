# Drawing-to-Quote 製程審查與多元估價系統

依《多張製作圖自動製程審查系統》規劃落地的 **版本 A/B**：零件資料（人工或 AI 讀圖後填入）→ 多條製程路線自動估價 → 推薦路線、風險、降本建議 → 一鍵輸出 Excel 報價分析與詢價單。單價採 **台灣南部（高雄／台南）加工成本價、不加價**，估價比例可調，並可自行回填校正。

## 離線單機版（2D 圖面辨識 + 多張估價統計）

| 平台 | 啟動 |
|---|---|
| Windows | 雙擊 `START-Windows.bat`（免安裝，用內建 PowerShell 開本機伺服器；有 Node.js 時改用 Node） |
| macOS / Linux | `./start-mac-linux.sh`（Node.js 或 Python 3） |
| 打包發給同事 | `node tools/build-offline.js` → `dist/Drawing-to-Quote-離線版.zip`（約 13 MB，解壓即用） |

所有函式庫與 OCR 字庫都在 `vendor/`（pdf.js 3.11、tesseract.js 5.1 + 繁中/英文字庫），**完全不連網，圖面不會上傳**。

**直接雙擊 `index.html` 也能用全部功能（含 OCR）**：OCR 核心與字庫包成一般腳本（`vendor/ocr-inline/`，由 `tools/build-inline-ocr.js` 產生），在頁面內組成 Worker，不受瀏覽器 file:// 限制。START 啟動檔改為選用。

### 2D 圖面辨識流程

```
多張 DXF / PDF / PNG / JPG 拖曳進來
  ├─ DXF：直接讀 TEXT / MTEXT / 屬性 / DIMENSION 標註值 / CIRCLE（展開圖塊，支援 UTF-8 與 Big5）
  ├─ PDF：讀文字層（CAD 匯出 PDF）；無文字層或 SHX 線字 → 自動轉 OCR；多頁 = 多張圖
  └─ 圖片／掃描 PDF：加強版 OCR（engine/recognizer-browser.js）
       ① 約 300 dpi 重新取樣 → 自適應二值化（處理灰底、陰影、褪色）
       ② 翻拍螢幕/手機照片自動判斷：取最亮通道去摩爾紋 + 輕微模糊 + 去小雜點
       ③ 自動校正傾斜（±4°）、自動轉正（0/90/180/270°，以標題欄關鍵字判斷）
       ④ 去除圖框、表格、尺寸線（容許斷線），避免把線讀成「一」
       ⑤ 全頁辨識 + 直書尺寸方向辨識 + 數字專用（英文白名單）辨識
       ⑥ 斜引線孔/牙標註：±20/35/50° 各讀一次（轉正後順便去掉引線）
       ⑦ 標題欄裁切放大，稀疏＋表格兩種模式取信心高者
       ⑧ 配合公差旁的尺寸（Ø80 g6）裁切成單行放大重讀，以字形判斷 Ø（兩個封閉孔）
        ↓
規則式欄位辨識（engine/drawing-parser.js）
  ① 標題欄：圖號、CAD NO、品名、材料、數量、表面處理、熱處理 → 取標籤右方或下方的值
  ② 註記：N-ØD 孔、M 螺牙（含深度→深孔判斷）、PT/NPT/Rc 管牙、交叉孔/流道、清角、焊接、UP/DOWN 折彎、板厚 t=
  ③ 品質：±公差、+/- 上下限、H7/g6 配合等級 → 一般/中等/嚴；Ra 值或 ▽ 符號 → 粗糙度
  ④ 尺寸：最大三個線性尺寸 = 長寬高；最大 Ø = 外徑；帶 H 公差的次大 Ø = 內徑
  ⑤ 外形：直徑為主→圓件、板厚/折彎→鈑金、焊接+大尺寸→架構件、厚度遠小於長寬→板件
        ↓
每個欄位附信心色條（綠＝標題欄、黃＝推斷、紅＝猜測）與辨識依據；預覽圖上框出所有讀到的數字與標註
（紅＝已採用為長/寬/高/板厚/外徑，橙＝孔/牙標註，綠＝標題欄，藍虛線＝其他數字），放大後點框即可指定欄位
同一圖號有多個來源（DXF＋掃描 PDF）時逐欄位取信心高者合併，再加入估價
        ↓
多元製程估價 + 整批統計（材料別、外形別、製程別、資料來源、辨識平均信心）+ Excel 9 表
```

準確度（`node test/run-test.js` 內含回歸測試）：

| 來源 | 欄位正確率 |
|---|---|
| DXF | 100%（示範圖） |
| CAD 匯出 PDF（有文字層） | 約 95–100% |
| 掃描 PDF（灰底、傾斜 ±1.3°、雜訊、整頁轉 90°） | 26% → **95%**（零件名稱偶有漏字） |
| 手機翻拍螢幕（摩爾紋、斜引線、標題欄被切） | 長、寬、外形可正確讀出；斜向孔標註、中文註記仍需在圖上點選補正 |

**向量 PDF 幾何驗證（不靠 OCR）**：讀取 PDF 繪圖指令中的直線與圓 → ① 以線條畫出的 Ø 符號（小圓＋斜線）自動補成 Ø；② 依標題欄比例（或自動推定）把每個尺寸與圖上線長／圓直徑比對，吻合者標「圖面量測吻合 ✔」；③ 大的同心圓判為圓形外形。

**估價穩定性**：缺尺寸時依外形補合理預設值並警告（一定算得出價格），每張圖給「估價可信度」0–100 分（高 ±10%、中 ±20%、低 ±35% 可信區間），依據辨識信心、預設值數量、材料/表處是否明確、圖面量測驗證數計算；Excel 05 工作表與摘要列出區間。

粗糙度圖例（同一列 ≥3 個 Ra）視為說明不採用；一般公差表與標題欄數字不當尺寸。

座標式（連鎖）尺寸會自動辨認：同一欄的數字取最大值為寬、同一列單調變化的數字視為孔位不當外形；一般公差表（≤10 ≤100 ≤500）與標題欄內的數字不當尺寸。

準確度：DXF > CAD 匯出 PDF > 掃描圖 > 翻拍照片。DWG 請先另存 DXF 或 PDF。`samples/drawings/` 有三張示範圖（同一圖面的 DXF / PDF / PNG 版本）可試用。

## 使用方式

| 方式 | 指令 / 操作 |
|---|---|
| 網頁版 | 直接用瀏覽器開啟 `index.html`（免安裝、可離線） |
| 命令列 | `node cli.js samples/parts.csv -o out/報價分析.xlsx --project 專案名 --due 交期 --deadline 截止日` |
| 自訂單價 | 網頁「單價設定」修改後匯出 JSON，CLI 加 `--db 單價.json` |
| 測試 | `node test/run-test.js`（含估價與 DXF 辨識回歸測試） |

不需 `npm install`，Node 18 以上即可。

## 多元製程路線（每個零件自動產生 2～5 條並比價）

| 外形 | 路線 |
|---|---|
| 圓件/軸/環 | R1 CNC 車削（+三軸銑二次加工）、R2 車銑複合、R3 走心機（量產 ≥200）、R4 傳統車床（少量簡單件） |
| 方塊/治具 | M1 三軸多次裝夾、M2 五軸一次裝夾（≥4 面）、M4 銑削+快/慢走絲線割（嚴公差/清角/模具鋼）、M5 改焊接/組合件（實體率 <45%） |
| 厚板件 | M3 雷射下料+CNC 銑面鑽攻、M3W 水刀下料（超出雷切厚度） |
| 薄鈑金 | S1 雷切+折彎(+焊)、S2 多折取代焊接、S3 沖壓模具（≥500 件）、S4 CNC 銑外形（1~5 件試作） |
| 架構件 | F1 型材鋸切+焊接+退火+後加工、F2 鋁擠型組合、F3 雷切榫接焊接 |

研磨（嚴公差/Ra0.4）、放電清角、表面處理、熱處理會依條件自動串入每條路線。

## 估價模型（南部成本價，不加價）

```
每個加工步驟成本/件 = 執行費（工時 × 機台費率，或 kg / 米 / dm² × 單價）+ 架模費 ÷ 數量
委外步驟成本/件     = max(單件 × 數量, 每批最低) ÷ 數量
估價/件 = Σ 步驟成本 × 類別比例(材料/加工/委外) × 整體比例 × 該圖估價比例%
        （+ 管銷%、利潤%，預設皆為 0 = 不加價）
```

- 每張圖在「多元製程估價」頁直接列出推薦路線的**每一個加工步驟**：計算依據、執行費、架模分攤、成本、比例、估價、小計，最後合計；其他路線可展開看各自步驟。Excel 另有「02B_加工步驟明細」工作表。
- **估價比例**：頁面上方可調整整體、材料、加工、委外比例與管銷/利潤；零件清單的「估價比例%」欄可針對單張圖調整。
- 議價下限 = 估價 −10%、急件參考 = 估價 +30%（可在單價設定修改）。
- 加工時間 = 切削移除體積 ÷ (基準去除率 × 材料切削性) + 精加工面積 × 公差/粗糙度係數 + 特徵工時 + 裝夾次數
- 批量分級 1/5/10/50/100/500 件，每一級自動選最便宜的路線

## 降本建議

每條建議都是 **把該條件修改後重新估價** 得到的實際差額，而非經驗百分比：放寬公差、粗糙度、內直角改 R、深孔/交叉孔簡化、PT 牙改 M 牙、減少加工面、替代材料、少量簡化表處、熱處理合併批次，以及資訊不足/表處未標示的提醒。

## 輸入欄位（CSV，見 `samples/parts.csv`）

圖號、CAD NO、零件名稱、材料、數量、外形(round/block/plate/sheet/frame，可空白自動判斷)、長L、寬W、高H、外徑OD、內徑ID、板厚T、實體率%、淨重kg、孔數、攻牙數、PT牙數、槽數、口袋數、深孔數、交叉孔數、內直角數、外螺紋數、退刀槽數、加工面數、折彎數、焊道長mm、雷切周長mm、公差(一般/中等/嚴)、粗糙度、表面處理、熱處理、備註

> 圖面判讀：把多張製作圖交給 Claude 讀圖，請它依上列欄位產出 CSV，再匯入即可（版本 A 半自動流程）。
