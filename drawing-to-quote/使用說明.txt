Drawing-to-Quote 製作圖製程審查與多元估價（離線單機版）
================================================================

【啟動】
  Windows ：雙擊 START-Windows.bat（免安裝；會開一個黑色視窗，使用期間不要關閉）
  macOS / Linux：執行 ./start-mac-linux.sh（需 Node.js 或 Python 3）
  瀏覽器會自動開啟 http://localhost:8765/index.html
  ※ 也可以直接雙擊 index.html，所有功能（含掃描圖 / 照片 OCR）都能用；第一次 OCR 需載入約 10 MB 字庫，稍等數秒
  ※ 直接雙擊 index.html 時，中文字型的 CAD PDF 也能讀文字層（字型對照表已內嵌於 vendor/pdfjs/cmaps-inline.js）
  ※ 本程式不會修改 Windows 的 PDF 預設開啟程式；若在檔案總管雙擊 PDF 打不開，請右鍵 → 開啟檔案 → 選擇其他應用程式 → 勾選「一律使用此應用程式」

【操作流程】
  1. 「圖面辨識」頁：一次拖曳多張製作圖（DXF / PDF / PNG / JPG）
  2. 核對每張圖辨識出的欄位（左側色條：綠＝標題欄讀到、黃＝註記推斷、紅＝猜測請確認）
  3. 按「全部加入估價」
  4. 「多元製程估價」看每張圖 2~5 條製程路線與推薦；「降本建議」「統計」看整批分析
  5. 按「下載 Excel 報價分析」輸出 10 個工作表（含各圖加工步驟明細、詢價單）
  6. 頁面上方「估價比例」可調整整體、材料、加工、委外比例；預設為南部成本價、不加價

【核對辨識結果】
  每張圖的預覽上會框出讀到的數字與標註：紅框＝已採用的尺寸（標 L/W/H/T/Ø）、橙框＝孔/牙標註、
  綠框＝標題欄、藍虛線＝其他數字。點預覽放大後，點任一框即可把該數字指定為長/寬/高/板厚/外徑，
  或把孔/牙標註的數量加到孔數/攻牙數。

【辨識準確度建議】
  DXF（最準）> CAD 匯出的 PDF > 掃描 PDF / 圖片
  DWG 請在 CAD 另存為 DXF（R2000 以上）或列印成 PDF
  掃描圖建議 300 dpi 以上，標題欄清楚
  手機翻拍螢幕可用，但建議正對螢幕、整張圖入鏡；斜引線上的孔標註可能需在圖上點選補正
  板件若未讀到板厚會以紅色標示，請務必補上（影響材料與加工金額）

【單價】
  「單價設定」頁可修改材料（55 種）、機台費率（26 種）、表處（28 種）、熱處理（13 種）、特徵標準工時（鑽孔、攻牙、鉸孔、倒角、品檢…）、管銷利潤，存在本機瀏覽器（預設為台灣南部 2026Q4 成本價，頁面下方列出依據與出處）
  可匯出 JSON 備份或給其他電腦匯入

【資料安全】
  所有辨識與估價都在本機執行，圖面不會上傳到任何伺服器。

【命令列（選用，需 Node.js 18+）】
  node cli.js samples/parts.csv -o 報價分析.xlsx --project 專案名
