Drawing-to-Quote 製作圖製程審查與多元估價（離線單機版）
================================================================

【啟動】
  Windows ：雙擊 START-Windows.bat（免安裝；會開一個黑色視窗，使用期間不要關閉）
  macOS / Linux：執行 ./start-mac-linux.sh（需 Node.js 或 Python 3）
  瀏覽器會自動開啟 http://localhost:8765/index.html
  ※ 也可以直接雙擊 index.html，但掃描圖 / 照片的 OCR 會停用（DXF、含文字的 PDF 仍可用）

【操作流程】
  1. 「圖面辨識」頁：一次拖曳多張製作圖（DXF / PDF / PNG / JPG）
  2. 核對每張圖辨識出的欄位（左側色條：綠＝標題欄讀到、黃＝註記推斷、紅＝猜測請確認）
  3. 按「全部加入估價」
  4. 「多元製程估價」看每張圖 2~5 條製程路線與推薦；「降本建議」「統計」看整批分析
  5. 按「下載 Excel 報價分析」輸出 9 個工作表（含詢價單）

【辨識準確度建議】
  DXF（最準）> CAD 匯出的 PDF > 掃描 PDF / 圖片
  DWG 請在 CAD 另存為 DXF（R2000 以上）或列印成 PDF
  掃描圖建議 300 dpi 以上，標題欄清楚

【單價】
  「單價設定」頁可修改材料、機台費率、表處、熱處理、管銷利潤，存在本機瀏覽器
  可匯出 JSON 備份或給其他電腦匯入

【資料安全】
  所有辨識與估價都在本機執行，圖面不會上傳到任何伺服器。

【命令列（選用，需 Node.js 18+）】
  node cli.js samples/parts.csv -o 報價分析.xlsx --project 專案名
