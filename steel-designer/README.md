# 鋼構廠房 3D 設計器

單一 HTML 檔，瀏覽器直接開啟 `standalone.html` 即可使用（需連網載入 three.js）。

## 功能
- 結構模式：單跨門型剛架廠房、雙跨倉庫（中柱）、小鐵屋（單斜）、開放車棚
- 參數：跨度、總長、簷高、坡度、跨數、各開間柱距（可鎖定總長）、簷口／山牆出挑
- 型鋼選用：H 型鋼、方管、C 型鋼、圓鋼斜撐（CNS/JIS 常用斷面，含 kg/m、Ix、Zx）
- 自動配置：山牆柱、簷口繫樑、桁條、牆檁（扣除開口）、門窗框料、屋面／牆面 X 斜撐
- 外殼：鋼浪板、PU 浪板、EPS／岩棉夾層板、採光板；四面牆可個別開放；鐵捲門／門／窗開口
- 3D 預覽：點選構件顯示規格、長度、重量；尺寸標註；等角／前／側／俯視
- 工程三視圖：山牆立面、側牆立面、屋頂結構平面（SVG，含軸線與尺寸）
- 清單：鋼材裁切清單（含鋼板零件）、板材收邊、五金門窗、結構初檢（ASD）、估價單（含每坪單價）
- 匯出：複製 BOM 貼 Excel、下載 CSV、匯出 PNG

## 注意
結構初檢為方案階段選材參考，正式施工須經結構技師計算簽證；估價單價為 2026 年台灣參考行情，可於右側「單價設定」修改。
