# 鋼構廠房 3D 設計器

## 單機版（離線使用）
`dist/steel-designer-offline.html` 為單一 HTML 檔，已內嵌 three.js，下載後雙擊即可用瀏覽器開啟，不需網路、不需安裝。

## 功能
- 結構模式：單跨廠房、廠房＋內夾層（半樓層）、雙跨倉庫、小鐵屋、二層鐵屋、三層鐵屋（店住）、車棚
- 多層：1～3 層，各層樓高可調，主柱貫通至屋頂；樓板大樑、小樑、樓板（鋼承板 RC／花紋鋼板／格柵板／木地板）
- 內夾層：位置（靠左／右側牆或全跨）、深度、起訖開間、樓板高、夾層柱最大間距；自動配置夾層柱、大小樑、欄杆
- 鋼梯：依樓高自動計算級數與級高（≤185 mm，級深 260），多層採交錯雙跑並於樓板開口，含扶手欄杆
- 型鋼選用、裁切清單（含鋼板零件、踏板）、板材收邊、五金、結構初檢（ASD）、估價單（以總樓地板面積計算每坪單價）
- 3D 預覽（點選構件看規格）、工程三視圖、複製 BOM／CSV／PNG 匯出
- **匯出 2D 圖面 PDF**：A3 橫式圖框＋標題欄（案名、圖名、比例、圖號、日期、張次），自動選標準比例（1:50～1:500）並附比例尺；
  圖面含山牆立面、側牆立面、屋頂結構平面、3D 透視、鋼材裁切清單、估價單（200 dpi 點陣）
- **匯出 3D STEP**（AP214，單位 mm，Z 軸向上）：每支構件為獨立實體（依構件類別與規格命名），含底板、樓板、踏板、欄杆，
  可匯入 Creo、SolidWorks、Inventor、Fusion、FreeCAD。網頁版下載為 .zip（內含 .stp），單機版直接存 .stp

## 開發
修改 `index.html` 後執行：
```bash
npm install
npm run build   # 產生 dist/steel-designer-offline.html
```

## 注意
結構初檢為方案階段選材參考，正式施工須經結構技師計算簽證；估價單價為 2026 年台灣參考行情，可於「單價設定」修改。
