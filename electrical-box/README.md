# 電箱智慧排版與門件干涉檢查 Pro

單一 HTML 檔，離線可用（不需安裝、不需外部函式庫），直接用瀏覽器開啟 `electrical_box_layout_pro.html`。

## 功能
- **箱體資訊**：電氣箱名稱、圖號、設計者、背板 / 門板顏色（帶入 PDF 標題欄）。
- **箱內元件**：每個規格可自訂名稱、顯示顏色、W×H、數量、深度。
- **配線槽**：水平 / 垂直，可設 X/Y、長度、槽寬×槽高（含標準規格 25×25 ~ 100×100）、顏色；
  可一鍵產生「N 列 + 左右側槽」標準框架。自動排版與手動重整間隙都會避開配線槽。
- **門板 HMI / 按鈕**：HMI 4.3/7/10/15 吋、按鈕 Φ16/Φ22/Φ30、緊急停止、指示燈、選擇開關、自訂圓形 / 矩形；
  設定中心座標、外框（頭部）尺寸、開孔尺寸、門內伸入深度、顏色。門板正視圖可拖曳定位。
- **點選即可修改（屬性面板）**：在圖面點選元件、配線槽、HMI／按鈕，右下角屬性面板可直接改名稱、顏色（含常用色票，
  門件依 IEC 60073 顏色意義提示）、尺寸、深度、位置；側欄卡片編號按鈕「⌖」可反向在圖面中選取。
- **多選對齊（門板按鈕適用）**：Shift／Ctrl＋點選或框選多選，以第一個選取為基準做靠左／左右置中／靠右／靠上／上下置中／靠下、
  水平／垂直均分、固定中心距橫排／直排、整組置中於門板、統一顏色與規格、複製／刪除。
- **操作輔助**：拖曳格點吸附（預設 5 mm）、方向鍵微移 1 mm（Shift 10 mm）、Ctrl+Z 復原、Ctrl+D 複製、Delete 刪除、Ctrl+A 全選。
- **排版健檢（即時）**：拖曳或調整元件時，同步顯示重疊、間距不足、超出寬度（紅框、橘框標示），並比較
  「目前排版 / 依目前順序緊縮 / 全自動最佳」三種方案的高度，可一鍵套用；可疊加最佳排版虛影對照。
- **建議最小尺寸 / 預留空間**：依預留擴充 %（以元件面積計）算出建議最小背板，畫面以綠色斜線顯示可用預留空間與擴充區；
  另依元件深度、門件伸入長度與安全間隙算出需求深度，並建議常用標準箱體 W×H×D（箱體−背板差值可設定）。
- **3D 模型 / STEP**：「3D 模型」視圖可旋轉、平移、縮放、切換等角／正視／側視／俯視，箱體可透明、門可開啟角度。
  「匯出 STEP」產生 AP214 組立檔：每個元件／配線槽／門件／配件為獨立零件，含中文名稱與顏色；
  圓形件（按鈕、開孔、電纜固定頭、鉸鏈、吊環）為真圓柱面，門板依門件實際開孔。已用 OpenCascade 驗證實體有效。
  線上預覽環境不允許下載 .stp 時，會自動包成 .zip。
- **電箱配件（⑨ 可勾選）**：箱體（自動＝建議標準箱或自訂 W×H×D）、門板、安裝背板、DIN 導軌（依元件列自動）、鉸鏈、門鎖／把手、
  電纜固定頭（底板開孔）、散熱風扇＋排氣濾網、接地銅排、壁掛耳、底座、吊環、LED 照明、門控開關、圖面袋、銘牌。
  配件同步進入 3D、STEP、PDF 材料表與 CSV。
- **鋁擠型框架箱**：⑨ 箱體型式可選「鈑金箱／鋁擠型框架箱」。鋁擠型可選骨架 2020／3030／4040／4545、門框 2020／3030、
  封板（壓克力、PC 耐力板、鋁複合板、鈑金）與鋁擠色；鋁擠斷面含 T 槽與中心孔。切換時自動套用完整配件：
  三向角連接座、L 角碼、背板固定橫桿、鋁擠型鉸鏈、U 型把手、磁吸門扣、調整腳或腳輪、槽蓋條、T 型螺帽（估算），
  並輸出「鋁擠型切料表」（長度、數量、端面攻牙、參考重量）與「封板裁切表」（含插槽深度、四角避讓、開孔）。
  「✔ 完整配件」按鈕可一次勾選目前箱型的全部適用配件。
- **干涉檢查**：門件本體投影 × 箱內元件 / 配線槽，比較 箱體深度 − 元件深度 − 伸入長度 − 安全間隙。
- **PDF 尺寸圖（A3 橫式）**：
  1. 背板配置圖：座標尺寸（基準點左上角）、總寬高、元件 P 編號、配線槽 W 編號。
  2. 門板開孔圖：開孔中心座標、HMI 開孔尺寸、按鈕 Φ、鉸鏈側。
  3. 3D 外觀圖：門關閉外觀＋門開 100° 內部（箱體透明）。
  4. 材料表：設計摘要、元件 / 配線槽 / 門件開孔明細（自動分頁）。
  比例自動選用標準比例（1:1、1:2、1:2.5、1:4、1:5、1:10…），列印請選「實際大小 / 100%」。
- 匯出 CSV（含元件、配線槽、門件）、PNG、專案存檔（瀏覽器 localStorage）。

> HMI / 按鈕預設尺寸為常見規格參考值，實際開孔與深度請依採購型錄確認。
