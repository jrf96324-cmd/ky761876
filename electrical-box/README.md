# 電箱智慧排版與門件干涉檢查 Pro

單一 HTML 檔，離線可用（不需安裝、不需外部函式庫），直接用瀏覽器開啟 `electrical_box_layout_pro.html`。

## 功能
- **箱體資訊**：電氣箱名稱、圖號、設計者、背板 / 門板顏色（帶入 PDF 標題欄）。
- **箱內元件**：每個規格可自訂名稱、顯示顏色、W×H、數量、深度。
- **配線槽**：水平 / 垂直，可設 X/Y、長度、槽寬×槽高（含標準規格 25×25 ~ 100×100）、顏色；
  可一鍵產生「N 列 + 左右側槽」標準框架。自動排版與手動重整間隙都會避開配線槽。
- **門板 HMI / 按鈕**：HMI 4.3/7/10/15 吋、按鈕 Φ16/Φ22/Φ30、緊急停止、指示燈、選擇開關、自訂圓形 / 矩形；
  設定中心座標、外框（頭部）尺寸、開孔尺寸、門內伸入深度、顏色。門板正視圖可拖曳定位。
- **干涉檢查**：門件本體投影 × 箱內元件 / 配線槽，比較 箱體深度 − 元件深度 − 伸入長度 − 安全間隙。
- **PDF 尺寸圖（A3 橫式）**：
  1. 背板配置圖：座標尺寸（基準點左上角）、總寬高、元件 P 編號、配線槽 W 編號。
  2. 門板開孔圖：開孔中心座標、HMI 開孔尺寸、按鈕 Φ、鉸鏈側。
  3. 材料表：設計摘要、元件 / 配線槽 / 門件開孔明細（自動分頁）。
  比例自動選用標準比例（1:1、1:2、1:2.5、1:4、1:5、1:10…），列印請選「實際大小 / 100%」。
- 匯出 CSV（含元件、配線槽、門件）、PNG、專案存檔（瀏覽器 localStorage）。

> HMI / 按鈕預設尺寸為常見規格參考值，實際開孔與深度請依採購型錄確認。
