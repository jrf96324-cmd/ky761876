# Obsidian 工程知識庫（Vault）

## 使用方式
1. 安裝 Obsidian → 「開啟資料夾作為 Vault」→ 選擇本 `obsidian-vault` 資料夾
2. 設定已預先完成：新筆記進 `00_收件匣`、附件進 `99_附件/圖片`、範本資料夾 `90_範本`、日誌進 `07_日誌`
3. 建議安裝社群外掛：**Dataview**（首頁表格）、**Templater**（可選）、**Obsidian Git**（自動同步到 GitHub）
4. 開新專案：複製 `01_專案 Projects/_範例專案-P2026-001` 並改名
5. 新增元件：在 `02_元件庫` 對應類別下，插入範本 `T02_元件卡`

詳細路徑說明見 [[00_首頁 Home]]。
